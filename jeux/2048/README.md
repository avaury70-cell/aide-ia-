# Faïence 2048

Jeu de réflexion dans le style de 2048, en un seul fichier HTML sans dépendance.

**Jouer :** ouvrir `index.html` dans un navigateur (double-clic suffit), ou le servir avec n'importe quel hébergement statique (GitHub Pages, Netlify…).

## Commandes

- Flèches, `ZQSD` ou `WASD` pour déplacer les carreaux
- Glisser du doigt sur le plateau (mobile)
- `U` ou le bouton **Annuler** pour revenir d'un coup

## Fonctionnalités

- Animations de glissement, fusion et apparition
- Score, record et partie en cours conservés dans le navigateur
- Écran de victoire à 2048 avec possibilité de continuer
- Thème clair / sombre automatique
